# מעוף: אתרי נדל"ן קולנועיים 🎬🏡

עסק שירות לסוכני נדל"ן ויזמים: **אתר לנכס שבו הקונה גולל ו"טס" לתוך הבית**, כמו בסרט. הלידים מגיעים ישר לוואטסאפ של הסוכן.

| מה | איפה |
|---|---|
| דף המכירה של העסק (לשלוח לסוכנים) | `index.html` |
| אתר לדוגמה: "וילה אלמוג" | `demo/` |
| ערכת מכירות: למי פונים, הודעות מוכנות, תשובות להתנגדויות, יעדים | **`SALES-KIT.md`** ← להתחיל כאן |
| הגדרות (מספר וואטסאפ) | `config.js` |
| משחק "יאללה דבר!" (הפרויקט הקודם) | `game/` |

## מחירים (בדף המכירה)
- **נכס בודד:** ₪1,490 חד-פעמי
- **סוכן פרו:** ₪790 לחודש (עד 3 נכסים בחודש, עם מיתוג)
- **פרויקט יזמי:** מ-₪4,900 (כולל הדמיית תלת-ממד)
- **תוספת צילום רחפן:** ₪900

כל המחירים נמצאים ב-`index.html` וקל לשנות אותם.

## 3 צעדים לעלייה לאוויר
1. **ממלאים את מספר הוואטסאפ** ב-`config.js` (שדה `WHATSAPP`, בפורמט `972501234567`).
2. **מעלים לאוויר בחינם:** vercel.com ← Add New Project ← בוחרים את הריפו ← Deploy. בלי שום הגדרה.
3. **פותחים את `SALES-KIT.md` ושולחים את 20 ההודעות הראשונות.**

## איך בונים אתר ללקוח
1. מקבלים מהסוכן סרטון רחפן, תמונות ופרטים (הרשימה המלאה ב-`SALES-KIT.md`, סעיף 6).
2. פותחים סשן עם Claude, מעלים את החומרים, ומבקשים: *"תבנה אתר קולנועי לנכס, כמו וילה אלמוג"*.
3. ממלאים את מספר הוואטסאפ של הסוכן ב-`data-whatsapp` בטופס (בקובץ `index.html` של הנכס).
4. מעלים ל-Vercel כפרויקט נפרד, או כתיקייה חדשה בריפו הזה, למשל `/villa-cohen/`.

## הערות טכניות
- גלילת הווידאו דורשת שרת עם תמיכה ב-Range. Vercel ו-Netlify תומכים. לבדיקה מקומית: `node demo/.claude/serve.mjs 5182`.
- הסרטון של הדמו הוא הדמיית תלת-ממד שנוצרה בקוד (נכס דמיוני), כך שאין בעיית זכויות יוצרים.
- קידוד וידאו של לקוח לגלילה (חובה: כל פריים הוא keyframe):
  `ffmpeg -i INPUT.mp4 -an -vf "scale=1920:1080,fps=30" -c:v libx264 -g 1 -crf 28 -movflags +faststart flythrough.mp4`
