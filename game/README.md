## 🚀 להתחיל למכור – 3 צעדים (בערך 15 דקות)

### צעד 1: למלא 2 שדות ב-`js/config.js`
```js
SELLER_WHATSAPP: "972501234567",   // המספר שלך, בלי 0 בהתחלה
PAYMENT_URL: "",                   // אופציונלי: קישור Bit / PayBox / Stripe
```
- אם `PAYMENT_URL` ריק, הלקוח לוחץ "לפתוח הכל" ונפתחת שיחת וואטסאפ אליך. אתה שולח לו פרטי Bit/PayBox, והוא משלם.
- אפשר לשנות גם את `PRICE` ואת `CUSTOM_PACK_PRICE`.

### צעד 2: להעלות לאוויר (בחינם)
**Vercel (הכי פשוט):** נכנסים ל-vercel.com ← Add New Project ← בוחרים את הריפו הזה ← Deploy. אין צורך בשום הגדרה, זה אתר סטטי.
אפשרות אחרת: **GitHub Pages**: ‏Settings ← Pages ← Branch: main ← Save.

### צעד 3: למכור
1. לקוח משלם ושולח לך צילום מסך בוואטסאפ.
2. אתה פותח את `https://האתר-שלך/admin.html` (בפעם הראשונה מדביקים את המפתח הפרטי, ראה למטה).
3. מקלידים את שם הלקוח ואת הטלפון שלו ← **"צור קישור הפעלה"** ← **"שלח בוואטסאפ"**.
4. הלקוח לוחץ על הקישור, וכל החבילות נפתחות אצלו. 🎉

הדף שומר את רשימת המכירות שלך (אפשר לייצא ל-CSV).

## 🔑 המפתח הפרטי – חשוב!
קודי ההפעלה חתומים דיגיטלית (ECDSA). **רק מי שמחזיק במפתח הפרטי יכול לייצר קודים**, כך שאי אפשר "לפרוץ" קוד או לנחש אותו.
- המפתח הפרטי נמסר לך בנפרד (קובץ `SECRET-private-key.json`). **שמור אותו במקום בטוח** (למשל הודעה לעצמך בוואטסאפ או בדרייב).
- **אסור להעלות אותו לגיטהאב.** הוא חסום ב-`.gitignore`.
- איבדת אותו? ב-`admin.html` לוחצים "צור מפתח חדש" ומעדכנים את `PUBLIC_KEY` ב-`config.js`. (הקודים הישנים יפסיקו לעבוד.)

2. **הוויראליות בנויה בפנים:** במסך הניצחון יש כפתור "לספר לחבר'ה בוואטסאפ" עם קישור למשחק.
3. **קבוצות פייסבוק:** "מארגנים מסיבת רווקות", "אמהות ב...", קבוצות של מילואימניקים, סטודנטים וגיבוש.

5. **עונות חמות:** פורים, ראש השנה, חנוכה, פסח (ערבי משפחה), קיץ (מסיבות רווקים/ות). לפני כל חג לעשות מבצע.
6. **קופון למשפיענים:** לתת למשפיעני משחקי קופסה / הורות קוד חינם בתמורה לסטורי.

## 🧩 מבנה הקבצים
| קובץ | מה יש בו |
|---|---|
| `index.html` | המשחק עצמו |
| `js/config.js` | **הגדרות מכירה (הקובץ היחיד שצריך לערוך)** |
| `js/words.js` | כל החבילות והמילים. להוספת חבילה מעתיקים בלוק ומשנים |
| `js/license.js` | אימות קודי הפעלה |
| `js/app.js` | לוגיקת המשחק |
| `admin.html` | דף הניהול שלך: יצירת קישורי הפעלה ורישום מכירות |
| `sw.js`, `manifest.webmanifest` | התקנה כאפליקציה ומשחק בלי אינטרנט |
| `tw.css` | עיצוב (Tailwind מקומפל, בלי תלות ב-CDN) |

**הוספת חבילת מילים:** ב-`js/words.js` מעתיקים בלוק `{ id: ..., name: ..., emoji: ..., free: false, words: [...] }` ומשנים. ‏`free: true` = חינם, ‏`false` = פרימיום.
**אחרי כל שינוי שמעלים לאוויר:** מעלים את המספר ב-`VERSION` בקובץ `sw.js` (למשל `yalla-v2`) כדי שהשחקנים יקבלו את העדכון.

אם משתמשים ב-class חדש של Tailwind שלא היה קודם, צריך לקמפל מחדש:
`npx tailwindcss@3.4.5 -o tw.css --content "./index.html,./admin.html,./js/app.js" --minify`
