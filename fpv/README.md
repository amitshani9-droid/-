# Go4FPV Builder: אפליקציית לימוד FPV (MVP)

מימוש שלב 1 (MVP) של מסמך האפיון: **שאלון חכם, קונפיגורטור ובודק תאימות**, ובנוסף 6 שיעורי יסוד, מסלול אישי של 9 שלבים, צ'קליסט בטיחות לפני טיסה ורשימת קניות עם קישורי שותפים.

## מבנה (monorepo, כמו באפיון)
```
fpv/
├── packages/compat/        מנוע התאימות: JS טהור, בלי AI, רץ גם בדפדפן וגם בשרת
│   ├── src/index.js        13 כללים + missingParts + totals + errorsIfChosen
│   ├── data/parts.json     60 חלקים ב-12 קטגוריות + 5 רחפנים מוכנים (BNF)
│   └── test/               13 טסטים (npm test)
├── apps/web/               React 18 + Vite + Tailwind, RTL, מובייל-פירסט
│   └── src/
│       ├── App.jsx         המסכים: בית, שאלון, מסלול, קונפיגורטור, קניות, שיעורים, בטיחות
│       ├── quiz.js         10 שאלות → פרופיל → בילד מומלץ (Go4FPV Preset)
│       ├── lessons.js      6 שיעורים + שאלת בדיקה, צ'קליסט טיסה, כללי LiPo
│       └── config.js       מזהה אפיליאייט של AliExpress Portals (ריק כרגע)
└── app/                    הבילד הסטטי (נבנה ע"י vite build), מוכן ל-Vercel
```

## הרצה
```bash
cd fpv/packages/compat && npm test          # 13/13
cd fpv/apps/web && npm install && npm run dev
npm run build                               # → fpv/app/
```
באתר שב-Vercel האפליקציה זמינה ב-`/fpv/app/`.

## כללי התאימות (`packages/compat/src/index.js`)
1. תאים בסוללה מול טווח ה-ESC · 2. סטאק מול פריים · 3. פרופ מול סטטור · 4. פרופ מול פריים · 5. חורי מנוע · 6. זרם ESC מול מנוע · 7. KV מול תאים · 8. מתח VTX · 9. שרשרת וידאו (מצלמה↔VTX↔משקפות) · 10. רוחב מצלמה · 11. מספר UART · 12. מחבר סוללה · 13. שלט↔מקלט · ובנוסף: חלקים חסרים.

כל כלל מחזיר `level` (error/warn/ok), את הקטגוריות המעורבות, והסבר קצר בעברית עם הצעה לתיקון. בקונפיגורטור, כל חלק שיוצר שגיאה מסומן עוד לפני שבוחרים בו (`errorsIfChosen`).

## ⚠ לפני השקה
- **המאגר הוא אב-טיפוס.** כל החלקים מסומנים `verified: false`. המפרטים והמחירים מקורבים, ויש להחליף אותם בפלט של `fpv-parts-extractor` ולאמת ידנית (תהליך האיכות שבאפיון).
- `config.js`: להכניס את מזהה ה-tracking של AliExpress Portals. בלי מזהה, הכפתורים מובילים לחיפוש רגיל באלי.
- מסך הרגולציה מפנה לאתר gov.il ולא מצטט חוק, כי הכללים משתנים (כפי שהאפיון ממליץ).
- **לא נבנה עדיין (שלב 2–3 ברודמאפ):** מורה AI, מדריך הרכבה מונפש, עוזר Betaflight, מחשבון ביצועים, תלת-ממד, התחברות (Firebase), האנגר וקהילה.
